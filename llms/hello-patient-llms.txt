# Hello Patient

> Hello Patient builds AI agents ("Mia") for patient conversations across voice, text, and web chat — automating appointment scheduling, insurance verification, patient intake, revenue-cycle (RCM) follow-up, no-show recovery, and patient recall for healthcare practices. HIPAA compliant and SOC 2 Type 2 certified. No public developer API is documented at this time; this profile is maintained by the API Evangelist network.
